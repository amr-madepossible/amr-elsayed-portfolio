## What is in this repository

- A responsive, single-page personal portfolio
- Experience-led case studies with **illustrative / reconstructed samples**
- Clear labeling of **UP TO** reported experience scale
- GitHub Pages deployment via GitHub Actions
- A recruiter-friendly structure designed around proof of capability

## Evidence policy

All numeric scale statements are framed as **up to / reported experience scale** and trace back to Amr's CV. Portfolio artifacts marked **ILLUSTRATIVE SAMPLE** use synthetic or reconstructed data and are not presented as confidential client/company files.
