# Amr Elsayed | Customer Success & Account Management Portfolio

Personal portfolio for **Amr Elsayed**, centered on Customer Success & Account Management, with Sales & Revenue Operations and Process Automation as supporting strengths.

## Portfolio structure

- `index.html`: the actual portfolio homepage
- `proof/`: six analytical case-study pages built as **ILLUSTRATIVE SAMPLES**
- `resume.html`: browser-readable résumé
- `styles.css`: shared visual system
- `.github/workflows/pages.yml`: GitHub Pages deployment workflow

## Evidence policy

Numeric figures taken from Amr's résumé are presented as **reported experience scale**, **reported examples**, or **up to** values. They are not presented as universal guarantees.

Portfolio artifacts are **reconstructed analytical samples using synthetic data**. They are designed to demonstrate methods such as health scoring, account segmentation, renewal risk analysis, forecast hygiene, cross-system reconciliation, SLA analysis, and root-cause prioritization. They are not confidential Microsoft, Concentrix, customer, partner, or financial files.

## Systems taxonomy

The portfolio uses the following primary classifications:

- **CRM:** Microsoft Dynamics 365; HubSpot
- **ERP:** SAP
- **ITSM:** ServiceNow
- **Content & collaboration:** SharePoint; Slack; Google Workspace
- **Business intelligence / analytics:** Power BI; Excel
- **Workflow automation:** Power Automate
- **Work management:** ClickUp
- **AI assistants:** Microsoft Copilot; ChatGPT; Claude; Gemini
- **Data / scripting:** Python (basic)

Dynamics 365 Sales is a CRM product, SAP is an ERP platform, and ServiceNow ITSM is an IT service-management platform. The portfolio avoids grouping these systems under a generic CRM/ERP heading.
